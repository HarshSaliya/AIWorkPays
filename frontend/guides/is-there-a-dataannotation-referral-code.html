Is there a DataAnnotation referral code?

The honest answer, why codes for sale are fake, and where the real referral programmes are.

The short answer

At the time of writing, DataAnnotation does not publish a public contributor referral programme. There is no programme page, no code to circulate, and nothing for anyone to legitimately hand you. If that changes, this page changes — it carries the date it was last checked for exactly that reason.

Why codes being sold for it are fake

When a platform has no public referral programme, there is nothing real for a code to unlock. So if someone is charging you for a "DataAnnotation referral code" — on Discord, Telegram, inside a paid course, anywhere — there is nothing behind it. The transaction only works in one direction.

This is worth saying plainly because the search term is popular, and popular search terms with no legitimate answer attract people selling one.

How to spot it

  • They're selling access. Real referral links are free and public. Nobody with a genuine link needs to charge for it.
  • They promise faster approval or guaranteed acceptance. No referral code does that anywhere. Acceptance is decided by the assessment.
  • They can't point at a programme page. Platforms that run referral programmes document them publicly.

So how do you actually get in?

Through the assessment, which is the only gate there is — and which is worth preparing for properly. See how the written assessment actually works for what's being scored and what fails people.

Where the real referral programmes are

Several platforms on this site do run public referral programmes, and where one exists the listing says so, shows the terms, and marks the link before you click it. Where no programme exists — like here — the listing shows a plain direct link and states that it earns nothing.

The full policy, and which listings carry a referral link, is on the referrals and disclosure page.
